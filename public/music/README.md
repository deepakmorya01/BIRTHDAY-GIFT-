# Music

Upload your background music file here.

## How it works

1. Put your audio file in this folder.
2. Open `src/config/music.ts` and set `fileName` to your file's name (e.g. `song.mp3`).
3. That's it — the music plays continuously across the entire site, never stopping between scenes.

The music starts after the visitor's first interaction (tap/click) so browsers allow audio playback.
